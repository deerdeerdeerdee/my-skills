# SOHO Opportunity Discovery

交付能直接用于选品核价、整理方案卡或发开发信的真实依据；不用搜索轮数、碎片文档数或自造术语代替进展。

本 skill 不自带搜索额度、登录态或外部发信权限。联网检索前读取 [工具路由与证据核验](references/tool-routing.md)，按任务选搜索或授权浏览器，尊重用户标签页，不绕过验证码。读过账号不等于有权发送邮件、发帖、询厂付费或改资料。

## 语言与档案铁律

- **短句大白话**：写进用户仓库的结论、台账和计划一律用大白话短句，尽量不超 40 字。
- **严禁黑话与碎文件**：禁用“资格首问 / 条件继续 / 条件草稿 / 对象级授权 / 实发正文 / 未知不填零 / 原位更新 / 项目闸门 / 研究批次”等词；成果直接写入现有总台账、商品核查表或阶段复盘，不按轮次新建碎文档。
- **留白诚实**：没查到的字段写“待查”或留空，不猜数据也不把网页 403/超时的报错记成业务结论。

## 模式选择与承接

先看当前日期、仓库主入口（`AGENTS.md` / `项目状态` / `任务看板` / 现行工作流），再定本轮干哪一件事：

1. **找品与市场方向**：指定产品打某国市场时，读 [指定产品与目标市场](references/product-market-entry.md)；要看大盘进口趋势，读 [贸易数据筛选方法](references/trade-data-method.md)（只看大方向，不在宏观表上耗太久）。
2. **按产品备 0→1 参考底牌**：不提前绑定单一工厂。从 1688 与国内电商、社媒、视频平台按 SKU 整理参考 MOQ 与阶梯价带——标品加 25%–40% 安全缓冲作为参考 EXW 区间，轻定制可花 5 分钟旺旺校准版费与真实起订门槛。
3. **图文与视频素材准备**：0→1 起步期可从国内平台采集产品图和视频，先去除水印与第三方商标，再按需用 AI 修复、生图或剪辑，用于官网、社媒与一页纸参考卡（仍须守住不虚构自有工厂与现有库存的底线）；开始打样或出单后逐步换成自拍实测图。
4. **集中找客与写信**：聚焦单一国家与同一类小 B 客群，按 30–50 家节奏收集活跃店主/采购姓名与直达渠道（Google Maps、独立站、IG 推荐、ImportYeti、展商/经销名单），戒掉低质匿名免费 B2B 榜。每家准备 90–130 词短开发信（看店观察 + 清晰产品参考方案 + 个人身份 + 5 秒可回小问题）及 Day 4 / Day 10 跟进草稿。
5. **实单比价与复盘**：收到客户明确尺寸、数量与目的地后，再向 2–3 家实盘厂发完整同口径询价单核成本与箱规毛重。负责人问进展时做只读速读；阶段收尾直接更新现有项目状态与阶段复盘。

## 真实性与外部授权边界

- 不虚构自有工厂、现货库存、已成交客户或好评数据；未获客户确认的参数标为待确认。
- 发开发信、发社媒帖、向工厂付打样费、下大货单或 Git 推送、生产部署，必须每次先经用户明确确认。
- 真实邮件原件、私聊截图、合同原文与账号密码留在仓库外；若操作仓库 CSV，跑通仓库既有校验脚本。
